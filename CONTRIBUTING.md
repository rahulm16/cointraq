# Contributing to cointraq

cointraq is maintained by its owner. Bug reports and feature suggestions are
welcome through GitHub Issues. Pull requests and external patches are not
accepted, including documentation changes and dependency updates; any submitted
pull requests will be closed without review. Please do not submit patches through
issues as a workaround.

You are welcome to use, fork, modify, and redistribute the project under its
license. This contribution policy applies to this upstream repository; it does
not restrict what you can do in your own fork.

## Reporting bugs

Search existing issues first. Include:

- The version or commit, browser, operating system, and Node.js/Postgres versions.
- Whether you run locally or use a hosted deployment.
- Steps to reproduce using dummy data, expected behavior, and actual behavior.
- Relevant error messages or screenshots with private information removed.

Do not attach `.env` files, credentials, session cookies, database dumps, real
transaction exports, or screenshots containing personal financial information.
Report suspected vulnerabilities privately as described in [SECURITY.md](SECURITY.md).

## Suggesting features

Describe the problem and the behavior you would find useful. Keep requests
focused on cointraq's scope: a self-hosted, single-user personal expense tracker
using whole rupees and the Asia/Kolkata time zone.

## Maintenance and support

Issues do not guarantee a response, a fix, or implementation of a suggestion.
There is no promised response time or release schedule. Please keep discussions
respectful and focused on the project. Setup instructions are in [README.md](README.md).
